拆开看里面

一个循环，
八个脚手架。

剥到最里面，Harness 就是一个 while 循环—— 不停地「想一步、做一步、看结果」。 其它零件，都是围着它搭的架子。

先记住这个公式

循环 + 工具 + 闸门
= 最小 Harness

智能全在大脑（模型）里。循环本身很「笨」—— 只负责一轮又一轮地转，把大脑的想法变成真实动作。

核心 · 循环
while 还没做完
+
手脚 · 工具注册表
读文件、跑命令
+
闸门 · 权限层
危险动作先拦住

Anthropic 管它叫 「a dumb loop」——笨循环，但够用。

循环里在转什么

想一步，
做一步，
看结果。

工程师叫它 TAO 循环（Thought–Action–Observation， 思考–行动–观察）。用大白话就是上面这三步。

🧠
思考

把该知道的上下文拼好，问大脑「现在该干嘛？」

⚡
行动

大脑说要调工具，Harness 校验后真正执行。

👁️
观察

把执行结果塞回对话，进入下一轮思考。

Claude Code 的版本：收集 → 行动 → 验证 → 再来一轮。

围着循环转的零件

九个零件，
点一个看一个。

几乎每个能上线的 Harness 都有这些。不用一次全懂，挑感兴趣的看。

💓
零件 #1

智能体循环

手搓第 02 阶段

这就是那个 while 循环。每轮：拼好上下文 → 问大脑 → 如果要调工具就执行 → 把结果塞回去 → 再来一轮。工程师叫它 TAO（思考–行动–观察）。

打个比方：像心脏跳动，每次泵血把养分送到全身。

循环什么时候停

知道何时停，
和知道怎么转一样重要。

停止条件不是小细节—— 它决定 AI 什么时候算「做完了」，什么时候该强行刹车。

✅大脑说「做完了」

不再要工具，直接给你文字答案——这是最自然的停法。

🔢转太久了

比如最多 50 轮，防止它原地打转、烧光预算。

📦记忆装不下了

上下文窗口满了，没法再塞更多对话历史。

🏁收到完成信号

程序里写好的「done」标记，明确告诉循环可以停了。

💥出了没法救的错

硬停。不能假装没事继续往下跑。

让「干活的」和「检查的」商量好什么叫完成，往往比改提示词更有效。

一条铁律

工具绝不能
让模型直接执行。

模型只能「申请」调工具。 真正动手的是 Harness——这样坏人没法用话术骗它跑任意代码。

步骤 1
大脑申请
返回结构化的工具调用请求
↓
步骤 2
Harness 校验
检查格式 + 权限
↓
步骤 3
Harness 执行
真正读文件、跑命令
↓
步骤 4
结果塞回
写入对话，进入下一轮

一个重要判断

模型越强，
脚手架越薄。

每个零件都藏着一个假设：「模型自己做不好这件事」。 模型变强了，对应零件就可以拿掉。

Harness 工程不是一直往上堆，而是随模型能力调厚薄。

会变薄的

复杂规划、多步推理辅助、部分上下文管理——模型自己能搞定了。

骨架始终要

持久存档、可验证的工具执行、清晰的权限控制——这些不会消失。
