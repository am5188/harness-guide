AM Harness · 工程指南

AI 会思考，
但它动不了手。

给它装上手脚的那套系统，就叫 Harness。

往下滚，30 秒看懂

先说清楚一件事

一个 AI 模型，
本质上只会「接话」。

你发一段文字，它接一段文字。就这么简单。

它可以在回复里写下「我应该打开 config.py」——
但它没有手，打不开任何一个文件。

模型是大脑，
Harness 是身体。

🧠
大脑 · 模型

负责想——理解、推理、做决定。 非常聪明，但离开身体，它什么也做不了。

🦾
身体 · Harness

负责做——调工具、记笔记、一步步循环、守住安全线。 把大脑的想法，变成真实的动作。

大脑想「打开文件」，身体真的把文件打开。

这副身体，
由四样东西组成。

🔁
一个循环

不停地「想一步 → 做一步 → 看结果」，直到把事做完。

🔧
一套工具

读文件、跑命令、搜网页——这是它的手和脚。

📁
一份记忆

把重要的事写下来，忘了随时能翻回去看。

🛡️
一道闸门

危险动作先问你一句「确定吗？」，不乱来。

其实你早就见过它

Cursor、Claude Code，
它们本身就是 Harness。

你以为在用「一个 AI」，其实你在用「模型 + 一副精心打造的身体」。 同一个模型，换一副更好的身体，就更能干活。

剥到最里面，
它只是一个循环。

懂「循环」你就懂了它的核心。用大白话写出来是这样：

harness 的心脏（伪代码）
while 还没做完:
    想法 = 问大脑(&quot;现在该干嘛？&quot;)

    # 大脑说要用工具（比如打开文件）
    if 想法.要用工具:
        结果 = 执行(想法.工具)
        把结果塞回去   # 再问一次大脑

    # 大脑说不用了，说明做完了
    else:
        return 想法.答案

真的，就这么点东西。剩下所有的复杂，
都是围着这个循环打转。
